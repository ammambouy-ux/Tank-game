# Steel Frontier — APK handoff (v1.4.0)

## Цель

Сделать Android APK из текущего проекта **Steel Frontier / «Стальной рубеж»**.

APK должен быть **гибридным**:

- одиночная игра WAVES работает полностью **офлайн**, без интернета;
- Online Multiplayer работает **при наличии интернета** и подключается к существующему Render/WebSocket серверу;
- при отсутствии сети игра **не должна блокироваться**: WAVES, гараж, прогресс и локальные сохранения продолжают работать;
- не нужно переносить игровой сервер внутрь APK;
- не нужно переписывать игру в нативный Android-клиент — сохранить существующую HTML5/Canvas-игру.

## Offline mode

В APK весь фронтенд и все локальные ресурсы должны находиться внутри приложения.

Минимальный набор:
- `index.html`
- `PackMusic/*`
- `PackSFXTanks/*`

Не полагаться на загрузку игры через:
`https://steel-frontier.onrender.com/index.html`

Игра должна стартовать, когда:
- телефон в авиарежиме;
- Wi-Fi отключён;
- мобильный интернет отключён.

### Важно про текущий код

Сейчас `index.html` уже умеет запускаться без Render и имеет fallback через `localStorage`.

Но APK-версия не должна ждать внешний интернет для CrazyGames SDK или игровых ресурсов.

Рекомендуется добавить APK/app mode flag, например:

`window.__STEEL_FRONTIER_APP__ = true`

и в APK-версии:
- не инициировать CrazyGames SDK;
- не ждать внешний SDK при старте;
- не обращаться к `api/music` и `api/sfx` для основной работы;
- использовать локальные `PackMusic/` и `PackSFXTanks/`.

Можно оставить CrazyGames-код в исходнике, но в APK он должен быть фактически отключён.

## Online mode

При наличии интернета APK должен подключаться к существующему серверу.

Основной сервер:
`steel-frontier.onrender.com`

Текущая функция `srvAddr()` в `index.html` выбирает сервер, а `wsUrl()` формирует:
`wss://steel-frontier.onrender.com`

Для APK можно жёстко использовать тот же production endpoint:
`steel-frontier.onrender.com`

Не создавать отдельный сервер для APK.

### Логика кнопки Online

Желаемое поведение:

1. APK запускается без интернета.
2. Пользователь может сразу нажать WAVES и играть.
3. Online либо:
   - активна и подключается к Render, если сеть есть;
   - либо показывает «Нет подключения», если сети нет.
4. Ошибка подключения к Online не должна влиять на WAVES.

Не использовать только `navigator.onLine` как единственный источник истины. Реальное подключение к WebSocket должно оставаться окончательной проверкой доступности Online.

## CrazyGames

CrazyGames SDK нужен только для браузерной/CrazyGames версии.

В APK:
- CrazyGames SDK не нужен;
- CrazyGames ads не нужны;
- CrazyGames Data Module не нужен;
- Instant Multiplayer/Invite API не нужен.

Не удалять CrazyGames интеграцию из production web-версии.

Лучше сделать отдельный APK build с условным app mode, а не ломать текущий `index.html` для Render/CrazyGames.

## Android packaging

Предпочтительно использовать **Capacitor** или аналогичную WebView-обёртку.

Требования:
- Android APK;
- landscape only;
- fullscreen/edge-to-edge по возможности;
- нормальная работа touch input;
- аппаратная Back button должна вести к паузе/меню, а не закрывать игру мгновенно;
- INTERNET permission должен быть включён, потому что Online опционально использует сеть;
- HTTP не нужен — сервер использует HTTPS/WSS.

Пример package id:
`com.ammambouy.steelfrontier`

## Render

Render продолжает использовать:

`GitHub → Render → steel-frontier.onrender.com`

APK не должен заменять Render.

Онлайн-архитектура остаётся:

`APK → WSS → steel-frontier.onrender.com`

Оффлайн-архитектура:

`APK → локальный HTML/JS/ресурсы`

## Админ-панель

`admin.html` и `server.js` нужны серверу.

Их не обязательно включать в APK UI.

Не переносить `ADMIN_KEY` в APK.

Можно добавить маленький app flag:

```js
const IS_ANDROID_APP = !!window.__STEEL_FRONTIER_APP__;
```

и использовать его для:

- отключения рекламных вызовов;
- отключения CG fullscreen;
- скрытия/изменения CG-only UI;
- сохранения полноценного Offline WAVES.

## Проверка перед выдачей APK

### Тест 1 — полный офлайн

Включить авиарежим.

Запустить APK.

Проверить:
- меню появляется;
- WAVES запускается;
- танк управляется;
- враги появляются;
- стрельба работает;
- XP и level-up работают;
- карточки улучшений работают;
- редкости работают;
- «Залп» работает;
- «Рикошет» работает;
- музыка/SFX работают;
- сохранения работают;
- после перезапуска прогресс сохраняется.

### Тест 2 — Online

Включить интернет.

Открыть Online.

Проверить:
- соединение с Render;
- создание лобби;
- вход второго игрока;
- старт игры;
- синхронизация игроков;
- выход из лобби.

### Тест 3 — плохая сеть

Начать игру.

Отключить интернет.

Проверить:
- Offline/Waves не ломается;
- игра не возвращает пользователя в меню;
- Online показывает ошибку только для Online;
- после возврата сети Online снова может подключиться.

### Тест 4 — ресурсы

Без сети проверить, что:
- `PackMusic` не требует Render;
- `PackSFXTanks` не требует Render;
- игра не зависит от CrazyGames SDK.

## Итоговый результат

Нужно получить:

1. Готовый debug APK для тестирования.
2. Готовый release APK, если возможно.
3. Краткую инструкцию установки APK.
4. Указание package id и versionName/versionCode.
5. Подтверждение, что WAVES работает полностью без интернета.
6. Подтверждение, что Online работает через существующий Render сервер при наличии сети.

## Важное правило

Не переписывать Steel Frontier с нуля.

Это уже готовая HTML5-игра. Основная задача — **упаковать существующую игру локально для Android и добавить корректный hybrid online/offline режим**, сохранив текущую игровую логику и web/CrazyGames версию.
