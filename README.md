# Стальной рубеж — онлайн-кооператив (2–4 игрока)

В папке: `server.js` (сервер лобби), `index.html` (игра), `package.json`, `render.yaml`.
Сервер сам раздаёт игру по адресу сайта, поэтому играть нужно открыв адрес на Render.

## Как развернуть на Render (бесплатно)
1. Создай репозиторий на GitHub и загрузи в него эти 4 файла (кнопка «Add file → Upload files»).
2. На render.com: New → Web Service → выбери репозиторий.
   Build Command: `npm install`  ·  Start Command: `node server.js`  ·  Plan: Free.
   (Либо New → Blueprint: настройки возьмутся из `render.yaml`.)
3. Когда сервис запустится, открой его адрес вида `https://имя.onrender.com` — это и есть игра.
4. В игре: В БОЙ → ОНЛАЙН → создай лобби и дай друзьям код (и пароль).

Примечание: бесплатный Render «засыпает» через ~15 минут без запросов, первое подключение
после сна может занять до минуты.

## Открыть игру из файла
Если открываешь `index.html` как файл, в окне «ОНЛАЙН» появится поле «Сервер» —
впиши туда адрес (`имя.onrender.com`).


## Надёжность сервера

Проект настроен для Render Web Service:

- `/health` используется как HTTP health check. Render периодически проверяет его и автоматически перезапускает экземпляр, если он перестаёт отвечать.
- `server.js` корректно обрабатывает `SIGTERM`/`SIGINT`, закрывает WebSocket-соединения и HTTP-сервер.
- необработанные исключения и Promise rejection завершают процесс с кодом `1`, чтобы Render поднял новый экземпляр вместо оставления сломанного процесса.

На бесплатном плане Render также может автоматически усыплять сервис после периода без входящего трафика; это не считается падением и при следующем HTTP/WebSocket подключении сервис запускается снова.

## Что исправлено в этой версии

- Улей создаёт не более 10 живых дронов одновременно и не создаёт новую группу, пока предыдущая полностью не уничтожена.
- Дроны улья имеют собственный интервал стрельбы и продолжают стрелять после первого выстрела.
- Босс-таран теперь делает длинный прямой рывок к цели, стреляет вне режима рывка и получает эффекты пыли, удара и разрушения стен.
- Боссы получили повышенное здоровье, сопротивление урону и усиленный урон/темп атак.
- Аптечка выпадает с вероятностью при каждом убийстве; удача игрока и убийство босса повышают шанс.
- В онлайн-бое кратковременный обрыв WebSocket больше не выбрасывает игрока сразу в меню: сервер удерживает слот около минуты, клиент пытается переподключиться и продолжить текущий бой.


## Обновление: артиллерия и миномёт

Миномёт и артиллерист больше не целятся всегда в текущую точку игрока. Атаки используют сглаженную оценку направления/скорости цели, упреждение, случайную погрешность и несколько паттернов залпа.

- Миномёт: одиночное упреждение, двойной залп с задержкой и веерный залп.
- Артиллерист: несколько паттернов, включая линию, вилку, коридор и двойной залп.
- Артиллерист меняет цель между залпами в кооперативе.
- Телеграфы синхронизируются с гостями через snapshot.


## Админ-панель

Панель доступна по адресу `/admin`. Для входа сервер должен иметь переменную окружения `ADMIN_KEY` — её задавай в Render → Environment. Ключ не хранится в коде и не должен добавляться в GitHub.

В панели доступны статус сервера, список игроков и лобби, кик игрока, закрытие лобби, объявление всем подключённым игрокам и ручной перезапуск процесса. Перезапуск вызывает корректное завершение Node.js; Render поднимет новый экземпляр.


## Обновление 1.2.0: танк «Тесла»

Новый враг (с 6-й волны). Вместо пушки — катушка; на корме три светодиода заряда.

- Заряд копится только когда цель в радиусе ~15 клеток и на линии огня нет стен. Каждая лампочка загорается примерно за 0,95 сек.
- Когда горят все три, катушка 0,45 сек «херачит» разрядами и тянет молнию-прицел, затем стреляет зарядом: 8 урона и оглушение на 1 сек (игрок не едет и не стреляет).
- После оглушения 0,8 сек невосприимчивости, чтобы несколько Тесл не держали игрока в стан-локе.
- Если цель пропала или закрылась стеной, заряд постепенно спадает.
- В кооперативе хост считает Теслу и рассылает состояние лампочек и зарядов; оглушение гостю передаётся отдельным сообщением.

Для обновления на Render замените файлы в репозитории GitHub (достаточно `index.html`, `server.js` и `package.json`) — Render пересоберёт сервис сам.


## Обновление 1.2.1: баланс и правки

- Дроны Улья больше не роняют аптечки, а их убийство не срабатывает как вампиризм.
- Аптечки исчезают через 10 сек (последние 3 сек мигают); таймер синхронизируется с гостями.
- Миномёт: упреждающий выстрел остаётся, плюс 1–2 мины в случайные точки рядом с игроком.
- Артиллерист: паттерны убраны. Один точный выстрел с упреждением плюс 3 мины в случайные места вокруг игрока; снаряды быстрее, круг падения больше (радиус 3 клетки, он же радиус взрыва).
- Оглушение от Теслы: 1 сек (было 0,5), после него 0,8 сек иммунитета.
- Огнемётчик: новая модель (раструб, боковые баллоны, задний бак), здоровье 3 → 6.
- Тесла: здоровье 4 → 7.


## Обновление 1.2.2: Призыватель

- Оглушение Теслы теперь 1 сек вместо 0,5.
- Босс «Разрушитель» (таран) удалён и заменён на «Призывателя»: держит дистанцию, стреляет веером из трёх зарядов, каждые ~8 сек замирает на 1,3 сек и призывает 3 танка (4 с 20-й волны). Пока призванные живы, он под барьером и получает на 50% меньше урона. Если босс погибает, призванные танки уничтожаются. Порядок боссов прежний (4-й босс, волна 20).

### Свои звуки (mp3)

Встроенный синтез можно заменить своими файлами. Создай рядом с игрой папку
`PackSFXTanks` и положи туда `.mp3`, назвав файл по имени события
(`shoot.mp3`, `boom.mp3`, `tesla.mp3`, ...) — полный список в
`PackSFXTanks/README.txt`. Если файл найден, играет он; если нет — остаётся
запасной синтезированный звук. Можно класть варианты `shoot1.mp3`,
`shoot2.mp3` — будет играть случайный.

- На сайте (Render): залей папку `PackSFXTanks` в репозиторий рядом с
  `index.html`; сервер раздаёт файлы сам (маршруты `/api/sfx` и
  `/PackSFXTanks/*`).
- При запуске из файла: положи `PackSFXTanks` рядом с `index.html`.
