# Steel Frontier — локальные профили

С версии 1.5.7 профиль игрока сохраняется на устройстве, без отдельного аккаунт-сервера и облачной базы.

## Поведение

- При первом запуске можно создать локальный профиль или играть гостем.
- Локальный профиль содержит идентификатор, никнейм и дату создания.
- Профиль хранится в localStorage текущей версии игры.
- Игровой прогресс продолжает использовать существующую систему сохранений.
- Создание профиля из гостевого режима не сбрасывает монеты, рекорд или открытые танки.
- При следующем запуске локальный профиль автоматически восстанавливается.
- Можно изменить никнейм или удалить профиль.
- Удаление профиля не удаляет игровой прогресс.

## Ограничения

- Профиль не переносится автоматически между браузером, APK и другим устройством.
- Очистка данных браузера/WebView или удаление приложения может удалить локальные данные.
- Локальный профиль — это профиль на данном устройстве, а не защищённая серверная учётная запись. Он не использует пароль и не подтверждает личность.
- Google Sign-In убран: без серверной или облачной учётной записи он не обеспечивает восстановление прогресса.

Для будущего переноса можно добавить экспорт/импорт резервной копии сохранения. PostgreSQL, OAuth и переменные окружения для аккаунтов не требуются.
