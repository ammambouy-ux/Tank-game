СВОИ ЗВУКИ — папка PackSFXTanks
================================

Клади сюда свои файлы в форматах .mp3, .wav или .ogg.
Имя файла = имя события (регистр не важен). Когда файл найден, игра играет
его вместо встроенного синтезированного звука. Если файла нет — звучит
запасной синтез, игра не ломается.

СПИСОК ИМЁН (что за событие):

  shoot       выстрел игрока
  eshoot      выстрел врага (обычный)
  ehit        попадание снаряда по врагу
  ehitboss    попадание по боссу
  playerhit   игрок получил урон
  boom        обычный взрыв / смерть врага
  explode     смерть босса
  blast       мощный фугас / таран
  mortar      пуск миномётной мины
  artillery   пуск артиллерийского снаряда
  tesla       разряд Теслы
  stun        оглушение игрока
  flame       огнемётчик (струя огня)
  heal        подбор аптечки
  coin        монета (пока не используется, зарезервировано)
  levelup     новый уровень / карточка улучшения
  buff        получен бафф
  wave        смена волны
  spawn       появление врага
  revive      «Второе дыхание»
  gameover    конец игры / появление босса

ВАРИАНТЫ: можно положить несколько файлов одного события — shoot1.mp3,
shoot2.mp3, shoot3.mp3 — тогда каждый раз проигрывается случайный из них
(лёгкое разнообразие). Цифра в конце имени отбрасывается.

ПРИМЕР:
  PackSFXTanks/shoot.mp3
  PackSFXTanks/boom.mp3
  PackSFXTanks/tesla1.mp3
  PackSFXTanks/tesla2.mp3

ВАЖНО для сайта (Render): положи папку PackSFXTanks рядом с index.html и
server.js, залей в репозиторий — сервер сам раздаст файлы.

ВАЖНО для запуска из файла (открыл index.html двойным щелчком): положи
папку PackSFXTanks туда же, где лежит index.html (или на одну папку выше).
